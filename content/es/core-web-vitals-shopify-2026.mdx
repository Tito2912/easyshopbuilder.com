# Core Web Vitals en Shopify (2026)

En Shopify la lentitud suele ser acumulativa: imágenes pesadas, apps, scripts de terceros y un tema demasiado cargado. La buena noticia: muchos quick wins son sencillos.

<h2 id="metricas">1) Métricas</h2>

- **LCP**: carga del contenido principal.
- **INP**: interacción (clics, formularios).
- **CLS**: estabilidad (saltos).

<h2 id="causas">2) Causas típicas</h2>

- hero pesada
- fuentes sin optimizar
- apps inyectando JS global
- popups/widgets demasiado pronto
- secciones/animaciones excesivas

<h2 id="quickwins">3) Quick wins</h2>

1. optimiza hero (formato/tamaño/compresión)
2. reduce apps
3. difiere scripts de terceros
4. reserva espacio para evitar CLS
5. limpia el tema

<h2 id="medir">4) Medición</h2>

- PageSpeed (lab)
- datos reales (GSC/CrUX)
- plantillas clave: home, colección, producto

<h2 id="checklist">5) Checklist</h2>

- hero optimizado
- apps mínimas
- scripts diferidos
- sin CLS
- monitorización mensual
