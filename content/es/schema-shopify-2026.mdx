# Datos estructurados en Shopify (2026)

Los datos estructurados (schema.org) ayudan a Google a entender tus páginas. En ecommerce: **Product + Breadcrumb primero**, luego amplías.

<h2 id="prioridades">1) Prioridades</h2>

1. **Product** (producto): precio, stock, reviews.
2. **Breadcrumb**: jerarquía (home → colección → producto).
3. **Organization / WebSite**: base de confianza.
4. **Article** (guías).
5. **FAQPage**: solo si la FAQ es visible y útil.

<h2 id="product">2) Schema Product</h2>

Debe coincidir con la UI:

- precio (incluida promo), moneda,
- disponibilidad,
- variantes sin inconsistencias,
- ratings/reviews solo si se muestran.

<h2 id="breadcrumb">3) Breadcrumb</h2>

Jerarquía estable:

- Home → Colección → Producto

<h2 id="faq">4) FAQ/Article</h2>

FAQ para objeciones reales (envío, devoluciones, compatibilidad). Evita bloques genéricos copiados.

<h2 id="validacion">5) Validación</h2>

- test en Rich Results,
- monitoriza Search Console,
- re‑test tras updates de tema/apps.

Errores típicos: doble markup, precio no coincidente, stock incorrecto, FAQ no visible.
