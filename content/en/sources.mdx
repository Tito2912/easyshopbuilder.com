# Sources

EasyShopBuilder aims to publish clear and actionable information. Here are the main types of sources we rely on.

## 1) Shopify documentation

- Official docs (features, SEO, checkout, Markets)
- Help Center / changelog entries when available

## 2) Product data

- Shopify App Store listings (features, pricing, limitations)
- Theme pages (compatibility, sections, performance claims)

## 3) Technical references

- Web performance references (Core Web Vitals, Lighthouse, best practices)
- SEO best practices (indexation, canonicals, structured data)

## 4) Corrections

If something is outdated or incorrect, contact us with the URL and correction details: [Contact](/en/contact).
