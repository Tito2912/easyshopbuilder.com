# Structured Data auf Shopify (2026)

Structured Data (schema.org) hilft Google, deine Seiten zu verstehen. Für E‑Commerce: **Product + Breadcrumb zuerst**, dann erweitern.

<h2 id="prioritaeten">1) Prioritäten</h2>

1. **Product**: Preis, Verfügbarkeit, Reviews.
2. **Breadcrumb**: Hierarchie (Home → Collection → Produkt).
3. **Organization / WebSite**: Trust‑Baseline.
4. **Article** für Guides.
5. **FAQPage** nur wenn sichtbar und sinnvoll.

<h2 id="product">2) Product Schema</h2>

Muss zur UI passen:

- Preis inkl. Sale, Währung
- Availability
- Varianten konsistent
- Reviews/Ratings nur wenn sichtbar

<h2 id="breadcrumb">3) Breadcrumb</h2>

Stabile Struktur:

- Home → Collection → Produkt

<h2 id="faq">4) FAQ/Article</h2>

FAQ nur für echte Einwände (Versand, Retouren, Kompatibilität). Keine generischen Copy/Paste Blöcke.

<h2 id="validierung">5) Validierung</h2>

- Rich Results Tests
- Search Console Monitoring
- Re‑Test nach Theme/App Updates

Häufige Fehler: Duplicate Markup, Preis mismatch, falscher Stock, FAQ nicht sichtbar.
