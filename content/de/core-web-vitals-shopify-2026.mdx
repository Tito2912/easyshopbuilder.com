# Core Web Vitals auf Shopify (2026)

Auf Shopify ist Performance selten ein einzelner Bug. Meist ist es kumulativ: schwere Bilder, Apps, Third‑party Scripts und ein überladenes Theme. Gute News: Quick Wins sind oft simpel.

<h2 id="metriken">1) Metriken</h2>

- **LCP**: Hauptinhalt lädt zu langsam.
- **INP**: Interaktionen sind träge.
- **CLS**: Layout springt.

<h2 id="ursachen">2) Typische Ursachen</h2>

- zu großes Hero
- Fonts nicht optimiert
- Apps mit globalem JS
- Popups zu früh
- zu viele Sections/Animationen

<h2 id="quickwins">3) Quick Wins</h2>

1. Hero optimieren (Format/Größe/Kompression)
2. Apps reduzieren
3. Third‑party Scripts deferen
4. Platz reservieren (CLS)
5. Theme aufräumen

<h2 id="messung">4) Messung</h2>

- PageSpeed (Lab)
- Field Data (GSC/CrUX)
- Key Templates: Home, Collection, Product

<h2 id="checklist">5) Checkliste</h2>

- Hero optimiert
- minimal Apps
- Scripts deferred
- kein CLS
- monatliches Monitoring
