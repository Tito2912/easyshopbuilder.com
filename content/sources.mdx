# Sources

EasyShopBuilder vise une information claire et actionnable. Voici les principales catégories de sources utilisées.

## 1) Documentation Shopify

- Documentation officielle (fonctionnalités, SEO, checkout, Markets)
- Centres d’aide et notes de mise à jour quand disponibles

## 2) Données “produit”

- Pages Shopify App Store (fonctionnalités, pricing, limites)
- Pages de thèmes (performances, compatibilité, sections)

## 3) Ressources techniques

- Références performance web (Core Web Vitals, Lighthouse, bonnes pratiques)
- Bonnes pratiques SEO (indexation, canonicals, données structurées)

## 4) Corrections

Si une information est erronée ou obsolète, contactez-nous avec l’URL et les éléments de correction : [Contact](/contact).
