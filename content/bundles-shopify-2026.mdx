# Bundles & upsells Shopify (2026)

Un bundle n’est pas juste “2 produits moins cher”. C’est une proposition : “voici le pack complet pour réussir X”. Bien fait, ça augmente l’AOV **et** réduit l’hésitation.

<h2 id="types">1) Types de bundles (simples)</h2>

- **Bundle complémentaire** : produit + accessoire essentiel.
- **Paliers quantité** : “2 = -X%, 3 = -Y%” (si marge OK).
- **Upsell** : version premium (“plus durable”, “plus rapide”).
- **Cross-sell panier** : ajouter un complément au panier.

<h2 id="ux">2) UX qui convertit</h2>

Règles :

- un seul message (bénéfice),
- visuel léger (pas de popups agressifs),
- un CTA simple (“Ajouter le pack”),
- pas de confusion sur le prix total.

<h2 id="marge">3) Marge & pricing : éviter la cannibalisation</h2>

Avant d’appliquer des remises :

- calculez la marge réelle (COGS + logistique),
- testez bundles “valeur” (accessoires) plutôt que discount,
- évitez les promos permanentes qui dégradent la perception.

<h2 id="mesure">4) Mesure : les bons indicateurs</h2>

Suivez :

- **AOV** (panier moyen),
- **RPV** (revenu par visite),
- taux de conversion,
- taux de retour / support (friction).

Un bundle qui augmente l’AOV mais baisse la conversion peut être un mauvais trade-off.

<h2 id="checklist">5) Checklist</h2>

- 1 bundle sur 1 produit star
- bénéfice clair + CTA simple
- prix total transparent
- marge validée
- mesure AOV/RPV + test A/B si possible
