# Core Web Vitals sur Shopify (2026)

Sur Shopify, la performance est rarement un “bug”. C’est souvent un cumul : **images lourdes**, **apps**, **scripts tiers** et un thème qui en fait trop. La bonne nouvelle : les quick wins sont souvent simples.

<h2 id="metriques">1) Les métriques (traduction business)</h2>

- **LCP** : le contenu principal met trop de temps → “site lent”.
- **INP** : interactions lentes (clics, formulaires) → friction.
- **CLS** : page qui bouge → baisse confiance + clics ratés.

Les CWV influencent surtout la conversion, et peuvent soutenir le SEO à contenu comparable.

<h2 id="causes">2) Causes fréquentes sur Shopify</h2>

- image hero trop lourde (home/collection),
- polices non optimisées,
- apps qui injectent du JS partout,
- popups/widgets chargés trop tôt,
- sections trop nombreuses dans le thème.

<h2 id="quickwins">3) Quick wins (ordre recommandé)</h2>

1. **Optimiser l’image hero** : bon format, taille, compression.
2. **Limiter les apps** : garder l’essentiel, supprimer doublons.
3. **Charger les scripts en différé** : trackers, chat, widgets.
4. **Réduire les shifts** : réserver l’espace (images, bannières).
5. **Nettoyer le thème** : sections inutiles, animations lourdes.

<h2 id="mesure">4) Mesure : ne pas piloter à l’aveugle</h2>

À suivre :

- PageSpeed Insights (lab),
- données réelles (field data) via Search Console / Chrome UX Report quand disponibles,
- pages clés : home, 1 collection, 1 produit, checkout.

Mesurez avant/après chaque changement important.

<h2 id="checklist">5) Checklist (simple)</h2>

- image hero optimisée (LCP)
- apps minimales + pas de scripts injectés partout
- scripts tiers retardés
- pas de layout shifts (CLS)
- monitoring mensuel + tests après changement de thème/apps
